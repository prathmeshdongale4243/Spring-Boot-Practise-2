## 📌 **Project Overview**

**Product Management System** is a web-based **CRUD application** developed using
**Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Thymeleaf and MySQL**.

The application provides a simple and user-friendly interface for managing
product information.

### **The system allows users to:**

- ➕ **Add Products**
- 📋 **View Products**
- ✏️ **Update Products**
- 🗑️ **Delete Products**
- ✅ **Validate Product Information**
- 📄 **View Products using Pagination**
- 💾 **Store Product Data in MySQL**

---
