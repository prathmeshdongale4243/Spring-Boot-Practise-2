## 📌 **Project Overview**

**Product Management System** is a web-based **CRUD application** developed using
**Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Thymeleaf and MySQL**.

The application allows users to:

- ➕ **Add Products**
- 📋 **View Products**
- ✏️ **Update Products**
- 🗑️ **Delete Products**
- ✅ **Validate Product Information**
- 📄 **Display Products using Pagination**

---

## 🚀 **Key Features**

| Feature | Description |
|---|---|
| ➕ **Create** | Add new product records |
| 📖 **Read** | Display all products |
| ✏️ **Update** | Modify existing product details |
| 🗑️ **Delete** | Remove product records |
| ✅ **Validation** | Validate name, price, quantity, category and description |
| 📄 **Pagination** | Display products page-by-page |
| 💾 **Database** | Store data in MySQL |
| 🎨 **Responsive UI** | Bootstrap-based user interface |
